# Python packages for running these notebooks natively on Windows (CPU only). PyTorch is NOT
# listed here: setup-native.ps1 installs torch==2.11.0+cpu from the PyTorch CPU index (or the CUDA
# build when run with -Gpu).
#
# The notebooks originally pinned gymnasium 0.28.1, stable-baselines3 2.0/2.1, ax-platform 0.3.4
# and wandb 0.15.12. None of those work on Python 3.12 with numpy 2 (the SB3 and wandb pins do not
# install; ax-platform 0.3.4 installs but cannot be imported), so these are the newest versions that
# do. They are the same pins as workshop-reinforcement-learning-for-robotics uses, so both
# repositories share one conda environment (rl-robotics) and either setup script can run first.
#
# Omitted on purpose:
#   sample-factory  - 2.1.1 needs numpy<2 and gymnasium<1, older releases need the unmaintained gym
#                     package, and the project has no Windows support, so sample-factory/ does not
#                     run here.
#   pygame          - gymnasium's classic-control renderer needs *a* pygame. stable-baselines3[extra]
#                     brings pygame-ce, which installs the same files, so never install pygame or
#                     gymnasium[classic-control] on top of it.
